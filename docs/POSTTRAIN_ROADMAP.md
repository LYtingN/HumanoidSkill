# S1–S0 后训练路线图：用反事实 J* 更新上层，再推广到 ego 数据

本文整理 2026-11 关于"怎么更新上层 S1"的讨论结论与项目推进计划。
架构与符号沿用 `ATTRIBUTION_ARCHITECTURE.md`（J、J*、h、h*、M、Ψ）。

最后更新：2026-11-09。

---

## 1. 现状：误差主要在上层，原因是数据源

DSRL iteration 935 的诊断（8192 回合，成功率 86.7%，约 1061 个失败回合）：

| 项目 | 数值 |
|---|---|
| 失败类型 | 掉落 20%，松手了没放进去 37%，超时还拿着 43% |
| 归因 | 执行约 15%，意图约 60%，无法归因约 24% |
| 跟踪误差 | 成功 3.8 cm，失败 3.1–4.3 cm，两者接近 |
| chunk 接缝 | 1.8 cm |

执行损失小，是因为用的是**摇操数据**：参考轨迹本来就是机器人在 S0 闭环里执行出来的，DiT 学到的 r
基本落在可执行区域，所以 J ≈ J*。剩下的意图误差是模仿误差：DiT 没学好放置阶段，不是 r 执行不了。

换成 **ego 采集 → 恢复 kinematic** 的数据后，参考轨迹里没有动力学约束：脚会滑、重心会出支撑域、
接触会穿模、人和机器人的身体结构也不一样。这时 J* 可能高、J 却很低，执行损失会明显变大。
**ego 数据才是分层归因真正发挥作用的场景**，摇操数据上主要做 S1 那一侧的验证。

ego 数据下，执行损失还要再拆成两部分：

| 部分 | 含义 | 由谁负责 |
|---|---|---|
| 可恢复部分 | S0 适应之后能补上的差距 | S0，按任务敏感度加权适应 |
| 不可恢复部分 G | S0 怎么适应都执行不了，r 本身不可行 | S1，作为可行性信号回传 |

## 2. 新颖点在哪里，不在哪里

"用世界模型或学到的评分模型去微调扩散策略"已经有不少工作，**不能作为新颖点**
（以下凭记忆列出，年份和细节需要核实）：

| 工作 | 内容 |
|---|---|
| Dreamer 系列（Hafner et al., 2020 起） | 在学到的潜空间世界模型里想象 rollout，奖励和价值的梯度沿模型传回策略 |
| DiWA（2025） | 扩散策略完全在学到的世界模型里做 RL 微调（DPPO 形式） |
| VLA-RFT、WMPO、World4RL（2025） | 用视频世界模型当模拟器，在里面 RL 微调 VLA 或扩散策略 |
| VIPER（Escontrela et al., 2023） | 视频预测模型的似然作为奖励 |
| Diffusion-QL（Wang et al., ICLR 2023） | 损失 = 扩散 BC 损失 − α·Q(s, a)，Q 的梯度沿完整去噪链传回策略 |
| PA-RL（2024） | critic 给扩散策略的候选排序，再蒸馏 |
| DRaFT（Clark et al., 2023）、AlignProp（Prabhudesai et al., 2023） | 文生图：可导奖励沿采样链反传，只反传最后 K 步更稳定 |
| SHAC（Xu et al., ICLR 2022） | 可导仿真器上短窗口解析梯度，窗口末尾接 critic |
| RWR、AWR、QVPO | 用自己采的样本做加权回归；QVPO 把它用到扩散策略的去噪损失上，按 Q 加权 |

这些工作的 WM 建模的是整个系统（策略输出 → 机器人 + 底层控制 → 物体 → 结果），只有一个策略层，
不区分失败该怪谁。

**本项目的新颖点是跨层的反事实分解，WM 只是工具**：

1. **理想执行分支 J\***：只建模"手按 r 完美运动时物体怎么响应"，不含 S0 和机器人动力学。
   奖励与 S0 无关，S0 换了也不用重训。
2. **按层归因**：J* − J 是执行损失，交给 S0；J* 本身不够高是意图损失，交给 S1。
3. **按任务敏感度加权适应 S0**：只在影响任务结果的地方改进，而不是均匀提高跟踪精度。
4. **可行性项 G**：把 S0 当前的能力当作学到的约束，反馈给 S1，避开双层优化的超梯度。

一句话：已有工作是"用 WM 给一个策略打分"，本项目是"用一个只建模任务物理的反事实分支，
在两层之间分配功劳"。

## 3. 更新 S1 仍然是难点，只是被转化了

怎么拿一个可信的分数去改 DiT 权重，这部分是成熟的。难的是拿什么分数、可不可信。

| S1 原本的难点（双层优化） | 分解之后 | 剩下的问题 |
|---|---|---|
| 梯度要穿过 S0 和物理仿真，传不回来 | J* 不含 S0 和物理，可导 | J* 是反事实量，数据里观测不到，M 在 h* 上可不可信 |
| S0 在变，S1 的目标跟着变 | J* 与 S0 无关，目标固定 | 可行性仍然取决于 S0 的能力，需要 G |
| 失败了不知道该怪谁 | J* − J 把两者分开 | 归因准不准取决于 J*；r 不可行时归因本身没有明确定义 |
| 奖励稀疏、时程长、需要换模式 | 分解解决不了 | 需要延续价值 V*，需要采样候选来换模式 |

本项目独有、已有工作不会遇到的两个难点：

1. **J* 是反事实量**：理想分支在真实数据里几乎不出现。用实际 h 训练的 M，到 h* 上本质是外推，
   在 cm 尺度上（h 与 h* 约差 3 cm）对动作是否敏感没有保证。放置、松手阶段接触最复杂，M 也最不准，
   而意图误差恰恰集中在这里。仿真里可用物理回放给标签，真实世界没有。
2. **r 不可行时归因没有明确定义**：G 取决于 S0 的能力上限，而 S0 的能力随适应而变，是循环依赖。
   这是分解之后剩下的双层耦合，变成了"估计 S0 的能力边界"。

## 4. 假设 J* 完美，S1 怎么更新

J* 完美时，更新 S1 退化成一个单层 RL 问题：环境是"S0 被替换成完美执行"的理想执行环境。
关键细节是**理想分支要从真实 rollout 的状态出发**。

```
循环:
  1. 用当前 S1 + S0 真实执行，收集状态 s_t（图像 + 本体状态），重点取失败回合
  2. 在每个 s_t 处分叉：
       z_1..z_N ~ N(0,I)，r_i = DiT_θ(s_t, z_i)               # 同一状态采 N 个意图
       J*_i = 从 s_t 出发理想执行 r_i，之后 S1 在理想分支里继续，直到结束
              （太长就截断：理想执行 k 个 chunk 后用 V*(s') 估计剩余部分）
  3. A_i = J*_i − mean_j(J*_j)                                # 同一状态内的相对优势
  4. 更新 DiT：
       L(θ) = Σ_i w(A_i)·‖ε_θ(r_i + 噪声, t, s_t) − 噪声‖² + β·L_BC
```

为什么从真实状态分叉：

1. **状态分布一致**：部署时 S1 看到的是真实执行后的状态；全程在理想环境里训练会有分布偏移。
2. **按 chunk 分配功劳**：同一状态、不同意图，结果差异只来自这一步的意图。
3. **解决整组优势为零**：现在 GRPO 按回合分组，86% 成功，很多组优势为 0；在失败状态上分叉后，
   组内有好有坏，信号集中在出错的地方。
4. **优势是纯意图的**：组内都是理想执行，A_i 不含 S0 噪声。这就是"意图损失给 S1"的具体实现。

第 4 步的更新器：

| 更新器 | 梯度类型 | 需要 J* 可导 | 说明 |
|---|---|---|---|
| 加权去噪（推荐先用） | 无梯度，按优势加权回归（同 QVPO / AWR） | 否 | 最稳，是 DiT 本来的训练方式，能保住多峰 |
| DPPO（只训最后 K 步） | 策略梯度（似然比） | 否 | 方差较大，需要随机去噪 |
| 直接梯度 | 路径梯度（同 Diffusion-QL / DRaFT） | 是 | `loss = −J*(DDIM_θ(z, s)) + β·L_BC`，用于微调细节 |

J* 完美时仍然存在的问题：

| 问题 | 原因 | 处理 |
|---|---|---|
| 计算量 | 每个候选都要在理想分支里继续到结束 | 用理想分支的价值函数 V* 截断 |
| 探索 | 某状态下 N 个候选全部失败就没有信号 | 加大采样噪声，或用 ∇J* 把候选推出原支撑后去噪投影回流形 |
| 理想与真实不一致 | S1 学的是理想执行下的最优意图 | 摇操数据影响小；ego 数据要加 G |
| 多峰塌缩 | 加权回归把分布推向单一模式 | BC 项，权重温度不要太低 |

## 5. 直接梯度的已知问题

**文献里已知的**：

1. **奖励被钻空子**：DRaFT、AlignProp 训练久了图像过饱和、趋同；Diffusion-QL 被吸到 Q 被高估的动作上，
   必须有 BC 项，α 很敏感。
2. **长去噪链反传不稳定**：只反传最后几步更稳，但最后几步只修细节，**换不了模式**。
3. **多峰性丢失**：最大化期望分数会把所有 z 推向同一个模式。
4. **梯度只给局部信息**：任务成功接近二值，需要光滑替代（余量、持有概率）。
5. **长时程**：沿模型反传太多步会混乱，SHAC 用短窗口 + critic。
6. **状态分布会变**：DiT 改了，闭环状态也变，需要定期刷新状态。

**本项目特有的**：

7. **M 的梯度从未被训练过（最关键）**：M 按"预测得准"训练，数据是实际 h；∂J*/∂h* 的方向没有监督。
   缓解：用物理回放生成反事实样本对直接监督 M 的动作响应；M ensemble 惩罚意见不一致的方向；
   限制 Lipschitz。
8. **代码里会截断梯度的地方**（`Diffusion/Humanoid-Diffusion/humanoid_diffusion/model.py`）：
   - DDIM 调度器 `clip_sample=True`，每步裁剪 sample，被裁剪的维度没有梯度；
   - `_action_result` 里 `action.clamp(min=self.action_min, max=self.action_max)`，贴边维度没有梯度；
   - `sample`、`predict_action` 带 `@torch.no_grad`，需要另写保留计算图的采样函数；
   - 夹爪宽度接近二值，在 J* 上的梯度可能很弱或很陡。
9. **J\* 不知道可行性**：梯度会把 r 推向理想但执行不了的轨迹；ego 数据下必须加 G。

**分工**：失败类型"松手了没放进去"和"超时还拿着"更像模式层面的错误（放哪里、何时松手）。

- 选模式：采样候选 + 物理回放打分 + 加权去噪；
- 调细节：直接梯度，只反传最后 K 步，加 BC 正则，只在 M 可信的阶段打开；
- 用直接梯度之前，先验证 M 的梯度：沿 ∇J* 小步修改 r，用物理回放检查 J* 是否真的上升。

## 6. 物体 WM 的角色与验收标准

不要以"完美 WM"作为前置条件。仿真里已经有完美 J*：**物理回放**——理想手 h* 作为运动学刚体在 MuJoCo
里驱动，物体走真实物理，再渲染图像给 S1。它准确、通用，但不可导，也只能在仿真里用。

WM 仍然必要：真实世界没有物理回放；物理回放每个候选都要跑仿真，代价大；直接梯度需要可导 J*。

**WM 的验收标准不是"预测完美"，而是和物理回放的排序一致**：同一状态下 N 个候选，M 排出的好坏顺序
与物理回放一致即可，因为加权去噪只用相对好坏。替换物理回放后，看 S1 更新的效果下降多少。

通用版 M 的设计（只用 DiT 的 ego_view 图像，不手工指定物体）见 Claude Doc
"S1–S0 对齐：上层更新与通用物体 WM 设计讨论"：轨迹 query（K 个手轨迹点的 3D 位姿 + 投影像素位置）
读取 DINOv3 patch token（需在 `forward_head` 池化之前取出）。

## 7. 推进计划

| 阶段 | 内容 | 要回答的问题 | 验收 |
|---|---|---|---|
| 0 | 物理回放（运动学手 + 真实物体物理 + 渲染） | 归因准不准 | 判为执行损失的回合，换成理想执行后大多成功；判为意图损失的，换了也不成功 |
| 1 | 用物理回放的 J* 更新 DP：失败状态分叉 + 加权去噪 | 按 J* 更新 S1 是否优于按 J（DSRL） | 成功率、样本效率 |
| 1' | 并行：只用图像的通用物体 WM | M 能否代替物理回放 | 与物理回放的排序一致率；替换后性能下降多少；按阶段分开看 |
| 2 | 换成 ego 数据（或代理） | 执行损失升到多少 | 重做阶段 0 的归因诊断 |
| 3 | 按任务敏感度加权更新 S0，与 S1 交替更新，加入 G | 分层归因是否优于只更新一层（核心实验） | 三组对比：只更新 S1 / 只更新 S0 / 按归因分别更新 |
| 扩展 | 把 S0 或动力学 token 送进 DiT（用法 B） | S1 知道 S0 的能力后，能否主动生成更可执行的意图 | ego 数据下执行损失是否下降 |

阶段 1 的最小改动：DSRL 的回报从 J 换成"失败状态分叉后的 J*"，仍只训练噪声策略，先验证信号；
确认有效后再把更新对象换成 DiT 权重，去掉 DSRL 受限于 base 支撑的上限。

**每个阶段都要有基线**，决定新颖点能否站住：

1. 阶段 1：DSRL 用 J。
2. 阶段 3：整系统 WM（把 S0 和机器人也建模进去，直接预测 J 去微调 S1，即 DiWA 式做法）。
3. 换 S0 实验：S0 更新或替换后，本方法的 S1 奖励不变，整系统 WM 必须重训。

**ego 数据**：阶段 2、3 依赖它。数据未到位时可以先构造代理：在摇操数据上注入重定向误差
（脚滑、重心偏移等），人为提高执行损失，让 S0 那条线提前开始。

## 8. 开放问题

1. 单个 chunk 的 J* 需要的延续价值 V*(s')：从理想分支 rollout 怎么学，截断多少个 chunk。
2. G 的估计：执行 critic E_φ(s, r) 以当前 rollout 的 J* − J 为标签，S0 每适应一轮重训一次；
   如何区分"S0 还没学会"和"物理上不可行"。
3. 没有反事实标签的真实世界里，M 怎样保证对 h* 的外推可信。
4. 在失败状态上，DiT 的 N 个候选里是否存在能成功的模式：决定加权去噪够不够，还是必须用梯度精修
   或动力学 token。这是阶段 1 开始前最先要做的检查。
5. 文献核实：确认没有"分层策略 + 反事实归因 + 世界模型"的直接前作。
