# 弥合 S1 与 S0 的动力学 gap：分层人形控制的级联系统优化

> 状态：idea 草稿（2026-11-19 按 Problem / Novelty / Method 重写）。
> 核心：S1（意图 / 规划）与 S0（全身控制）分开训练，二者之间存在**动力学 gap** 和多重 **mismatch**；本 idea 把 S1 ∘ S0 ∘ 物理 看成一个级联系统，以任务成功为共同目标，对两个模块做联合优化。

---

## 1. Problem

### 1.1 背景

现有系统：S1（DINOv3 + DiT diffusion，头部相机 + 本体）→ 32 帧显式全身参考 r（29 关节 + 2 夹爪 + 根朝向）→ S0（SuperMimic tracker）→ PD，每 8 步重规划一次。任务为 G1 抓放罐子，罐子半径 2.75 cm。

两层**分开训练**：

- S1：在演示数据上做行为克隆，学 r；
- S0：在 mocap 上做跟踪 RL，学"把任意 r 跟住"。

### 1.2 形式化

记 S1 输出 r = π₁(o)，S0 闭环 + 物理把它变成实际执行的轨迹 τ = Φ(r; s)。

```text
分开训练：  S1  min  ‖r − r_demo‖            （以为执行是理想的：τ ≈ r）
           S0  min  E_{r~mocap} d(Φ(r), r)   （对所有部位、所有 r 一视同仁）
真正目标：  max  J = E[ 任务成功( Φ(π₁(o)) ) ]
```

两个子目标的组合 ≠ 真正目标。差距来自下面两类问题。

### 1.3 动力学 gap：r ≠ Φ(r)

S1 是**运动学**规划器，默认参考会被理想执行；S0 是**动力学**执行器，实际执行受物理和自身能力约束。

1. **物理不可达**：S1 的参考可能违反动力学（平衡、力矩、负载），"运动学木偶"式的理想执行并不存在。
2. **跟踪误差在关键部位放大**：关节误差沿手臂累积，关节跟得不错时手仍会偏几厘米，与罐子尺寸同量级。
3. **负载 / 接触改变动力学**：抓起罐子后的身体动力学与 mocap 不同，S0 没见过。
4. **时间断裂**：S1 每 8 步重出 32 帧，段与段之间不连续；S0 50 Hz 闭环，两者频率不匹配。

### 1.4 Mismatch：两个模块彼此不了解

| 类型 | 表现 |
|---|---|
| **目标** | S1 优化"像演示"，S0 优化"均匀跟踪"（`body_pos` std 0.3 m，3 cm 手部误差仍拿 0.99），没有一方优化级联系统的任务成功 |
| **分布** | S1 的标签来自另一个控制器的实测关节；S1 的输出（站立前倾够物 + 负载）对 mocap 上训练的 S0 是 OOD；S0 执行出的状态对 S1 又是协变量偏移 |
| **能力 / 信息** | S1 不知道 S0 能做到什么，S0 不知道此刻什么重要；接口只有一条全身轨迹，单向传递 |
| **评估** | v3 后训练用物体 WM 逐步回归罐子状态来打分，在抓 / 放处误差大且自回归累积，S1 被一个不准的模型优化 |

### 1.5 为什么不能直接端到端

- 仿真不可微，接触结果不连续；
- 两层规模差异大：DiT 推理慢，S0 要在大规模并行仿真里做 RL；
- 两层同时更新容易**共适应塌缩**（各自迁就对方的缺陷）；
- S0 的通用性（mocap 跟踪能力）需要保留，不能和某一个 S1 绑死。

**核心问题**：在保留两层分工、各自可训练的前提下，如何显式建模并缩小 S1 与 S0 之间的动力学 gap 和 mismatch，并对级联系统做以任务成功为目标的联合优化。

---

## 2. Novelty

1. **把分层控制表述为级联系统优化。** 以 J = E[任务成功(Φ(π₁(o)))] 为共同目标，用显式的 gap 模型 Φ 连接两层。不同于两层分开训练（S1 行为克隆 + S0 mocap 跟踪），也不同于 π0 / VLA-Adapter 那种两层用同一批演示端到端训练（丢掉了 S0 的独立性）。

2. **gap 按物理性质拆成两部分建模。**
   - 平滑部分（身体、手在空中的运动）→ S0 + 身体 WM f_ω 组成的可微 gap 模型，推出 S0 **实际可达**的轨迹；
   - 不连续部分（接触结果）→ 不逐步预测，交给仿真真值训练的 **RM 分类器 + 价值模型**。

   S1 被评价的是"S0 真能做出来的东西"，而不是不存在的理想执行。

3. **双向适应。**
   - S1 → S0 方向：S1 经 Φ + RM 学会 **gap-aware 规划**，只提 S0 做得到且能完成任务的目标；
   - S0 → S1 方向：S0 在 S1 的实际输出分布、负载场景和按重要性加权的奖励上适应，变成 **task-aware 执行**。

4. **接口本身是被优化的对象**：从全身轨迹改为"部分目标 + 门控 KV"双通道，外加 S0 → S1 的上行通道，从结构上减少信息 mismatch；零初始化门控保证每一步改动都能退化回现状、收益可测。

5. **保持模块独立的交替优化**：块坐标式交替更新（一侧冻结），录制 KV 回放使 S0 的 RL 不需要 DiT 在回路里；提议者（S1）与裁判（f_ω + RM）分离，并用仿真真值做排序校验，防止 S1 钻裁判的空子。

## 3. Method

### 3.1 总体结构

```text
   图像 + 本体 [+ S0 状态 token] ──► S1（DiT，只有它看图像）
                     │                         │
          显式：部分目标 + 权重 w           latent：KV cache
                     ▼                         ▼
     S0：z = enc(部分目标, w) + tanh(g) · Reader(KV, 本体)，g 初始 0
         a = dec(z, obs_hist)  ──► PD                 （50 Hz 本体闭环）
                     │
                     └──► 上行：跟踪误差 / S0 critic / 摔倒概率 ──► S1

   ┌──────── gap 模型（仿真，特权状态）────────────────────────────┐
   │  Φ = S0 + f_ω ：r ──► 可达的身体 / 手 / 夹爪轨迹 τ̂（平滑，可微）  │
   │  RM(τ̂, 物体初始状态) ──► 接触结果概率 + 价值（不连续）           │
   └─────────────────────────────────────────────────────────┘
                     │ 级联目标 J 的估计（按 chunk 的优势）
          ┌──────────┴──────────┐
          ▼                     ▼
     更新 S1（gap-aware）    更新 S0（task-aware）     ← 交替进行
```

### 3.2 gap 模型：Φ 与 RM

**Φ：S0 闭环的可微代理**

- 由 S0 策略 + SuperMimic 身体 WM f_ω（小 MLP，50 Hz，可微）组成，输入 S1 的目标，推出 S0 实际可达的轨迹 τ̂。
- 只用仿真特权状态，不含视觉；只负责平滑部分，不跨接触推演物体。
- 训练数据包含负载场景，并随 S0 更新而重拟合（SuperMimic 本来就边训策略边训 WM）。
- gap 的直接度量：`Δ = d(τ̂, r)`，尤其是抓 / 放阶段的手部误差。

**RM：不连续部分的结果模型**

```text
RM( 物体初始状态(特权), τ̂ 中的手 / 夹爪轨迹, 夹爪指令 )
   → P(抓住), P(提起), P(放好), P(掉落 / 推倒) + 剩余价值
```

- 接触结果是分类问题：结果对初始条件极敏感，分类器能学陡峭边界，回归会把多种结果平均成不存在的状态。
- 标签来自仿真 rollout，几乎免费；目标为进度回归 + TD 损失（成功 +1、失败 −1）。
- 按 chunk 计算优势：`A = mean_k V(chunk 内第 k 步) − V(当前)`，只推 1–2 个 chunk，长期部分由价值补上。

### 3.3 优化 S1：gap-aware 规划

1. **提议**：S1 从仿真真实状态出发给出目标；
2. **投影**：经 Φ 得到可达轨迹 τ̂；
3. **打分**：RM 给出 chunk 级优势；
4. **更新**（两种信号，互为对照）：
   - **RECAP 式优势条件化（主方案，无需梯度）**：优势离散成若干档作为 DiT 的额外条件，用原扩散损失训练，推理时以最优档为条件；混入离线演示（约 0.6）防遗忘，演示配最优档。
   - **经 Φ 的级联梯度（可选）**：Φ 与 RM 对 τ̂ 都可微，`∂J/∂r = ∂RM/∂τ̂ · ∂τ̂/∂r` 给出 S1 输出上的梯度，可用于 RM 引导采样（类似 classifier guidance）或构造改进后的目标 r' = r + η∇ 做回归。
   - DSRL 噪声策略保留为基线。
5. **校验**：定期用真实仿真执行同一批候选，与 RM 排序比较（Kendall τ），并用新 rollout 给 RM 补标签。

### 3.4 优化 S0：task-aware 执行

- **加权跟踪奖励**：按部位权重 w 加权，高权重部位紧容差（手部到 cm 级），低权重部位放宽——跟准"重要的东西"，而不是均匀跟踪。
- **对齐分布**：训练分布加入 S1 实际输出的目标（站立前倾够物）、负载与接触扰动（夹爪随机挂载质量）。
- **任务项**：S0 适应阶段在跟踪奖励之外加入 RM 任务分，让 S0 直接对级联目标负责。
- 保留自身的本体闭环和 mocap 跟踪能力（显式通道始终存在），S1 只能通过接口调制它。

### 3.5 接口：减少信息 mismatch

**(a) 显式通道：部分目标（HOVER 式掩码指令）**

| 字段 | 含义 | S0 训练时怎么采样 |
|---|---|---|
| 手 / 夹爪位姿 | 躯干（或根）坐标系下的空间目标 | mocap 的 FK + 小扰动 |
| 躯干 / 头朝向 | 身体姿态、相机视野 | mocap |
| 底座速度 | 行走意图 | mocap |
| 夹爪指令 | 开度，绕过 tracker 直接执行 | 随机 / 演示 |
| 部位权重 w_{t,b} | 此刻哪个部位必须跟准 | 随机模式：手重、腿重、均匀、随时间切换 |
| 掩码 | 哪些字段本次给出 | 随机遮挡 |

- **直接缩小动力学 gap**：S1 不再指定腿和平衡这类动力学主导的部分，交给 S0 补全；S0 直接以手为目标，不受关节误差沿手臂累积的影响。
- 所有字段能在仿真里独立采样，S0 可以不依赖 S1 独立训练。
- 第一版 S1 输出格式不变，部分目标由 r 经 FK 计算，w 按规则生成（按手到罐子 / 箱子的距离和夹爪指令分阶段）；验证有收益后再让 S1 直接输出。

**(b) latent 通道：门控 KV**

- 取 S1 的观测条件 token + 动作 token 在去噪过程中的多层 K/V（DiT 自带的动作 token 即起 ActionQuery 的作用）。
- S0 内的 cross-attention 读取器以本体状态为 query，每个 50 Hz 控制步读同一份 KV——慢速意图被读成快速信号，缓解频率 mismatch。
- 零初始化门控 `tanh(g)`：g = 0 即纯显式接口。读取器属于 S0（`Policy.encoders` 的新接口）。
- 待确认：DiT 的条件接入方式（cross-attention 还是前缀）与去噪步数；DDIM eta=0 下最后一步动作 token 近似是 r 的函数，额外信息可能主要来自条件 token 和中间去噪步。

**(c) 上行通道：S0 → S1**

- 传 S0 内部的判断：按部位跟踪误差、S0 critic 值、f_ω 预测的摔倒概率（可选 S0 隐状态 z）。
- 小 MLP 编码成少量 token 追加到 S1 条件 token 之后，零初始化；离线演示没有这些信号，用可学习的空 token 占位并随机丢弃。
- 价值在信息内容而非延迟；需要更快反应时加**事件触发重规划**（critic 骤降或摔倒概率超阈值时立即重规划）。

### 3.6 级联优化流程（交替）

| 阶段 | 训练什么 | 怎么训 | 冻结 |
|---|---|---|---|
| 0 基线 | — | 测量现有系统的 gap（手部误差）与失败归因 | 全部 |
| 1 S0 接口扩展 | S0 | mocap + 随机遮挡部分目标 + 随机 w + 随机负载；确认行走跟踪不退化 | S1 |
| 2 读取器热启动 | 读取器 | 蒸馏：Reader(KV) 拟合 S1 显式输出在 S0 goal 空间的编码 | S1、S0 主体 |
| 3 S0 适应 S1 | S0 + 读取器 | 回放 KV：录 S1 rollout 的 (仿真状态, KV)，仿真重置到这些状态，S0 跑一个 chunk 做 RL；奖励 = 加权跟踪 + RM 任务分 | S1 |
| 4 S1 适应 S0 | DiT（+ 上行编码器） | 提议 → Φ 投影 → RM 打分 → RECAP（可选级联梯度），混入演示 | S0、读取器 |
| 5 交替 | 轮流 | 每轮后重拟合 f_ω、给 RM 补标签、读取器短暂重新适应；监控 gap 与任务成功率 | 一侧冻结 |

**防共适应塌缩**：每次只更新一侧；S1 混入演示、S0 保留 mocap 跟踪任务；RM 排序定期用真实仿真校验。

### 3.7 风险

1. **gap 模型本身不准**：f_ω 在负载下偏差大，RM 的输入就错了；需单独测量并随 S0 更新重拟合。
2. **RM 被钻空子 / 边界难学**：接触附近加密采样、补标签、排序校验。
3. **交替优化不收敛或振荡**：S0 改变后 S1 学到的 gap 过时；控制每轮更新幅度，必要时 S0 慢更新。
4. **KV 语义漂移**：S1 微调后读取器读不懂；KV 锚定正则、S1 只 LoRA 微调高层、读取器只读冻结中间层。
5. **门控打不开**：推动 g 增大只能靠 RM 任务分，RM 对接触不敏感时 g 会停在 0 附近。
6. **IDM 多解性**：低权重部位放宽后 S0 可能出现意外姿态（如身体挡住相机）。
7. **视觉域差**：只有 S1 看图像，Isaac RTX ↔ MuJoCo 渲染差异需单独处理。

### 3.8 最小验证实验

**先量化 gap 和 mismatch（动机是否成立）**

1. **gap 大小**：S1 参考上统计抓 / 放阶段 `d(Φ(r), r)` 的手部误差分布，对比罐子半径 2.75 cm。
2. **失败归因**：现有 DSRL 策略的失败分为"执行准但失败（意图）"与"执行不准（gap）"，估计两类占比。
3. **gap 模型精度**：`check_body_wm` 跑带罐子的情况，f_ω 推出的手轨迹与仿真真值对比。
4. **接触应分类而非回归**：v3 metrics 中 `held_acc` 与 `pos_err_cm` 随推演步数的变化。

**再验证各优化手段**

5. **S0 侧**：部分目标 + 加权奖励后，抓 / 放阶段手部误差是否下降，行走跟踪不变差。
6. **RM 可行性**：同一状态多候选上，RM 排序与仿真结果的 Kendall τ。
7. **S1 侧**：同一 RM 下 RECAP vs 级联梯度 vs DSRL。
8. **KV 通道**：KV 信息量探针（能否预测 r 预测不出的量）、读取器蒸馏、g > 0 vs g = 0。
9. **级联 vs 分开**：交替优化若干轮后，与"只更新 S1"、"只更新 S0"对比任务成功率与 gap。
