# HumanoidSkill

Humanoid skill learning and world-model experiments using
[SuperMimic-Reproduced](https://github.com/CuboiLeo/SuperMimic-Reproduced).

```text
humanoid_skill/
├── supermimic-reproduced/  # implementation, configuration, tests and documentation
└── data/residual_rl/       # local datasets; excluded from Git
```

Run implementation commands from `supermimic-reproduced/`.
See its [README](supermimic-reproduced/README.md) for environment setup,
training, checkpoint loading and evaluation.

Datasets, checkpoints, logs and virtual environments stay local.
The implementation is included as source files, with no nested Git repository.
Its MIT notice is retained in [LICENSE](supermimic-reproduced/LICENSE).
